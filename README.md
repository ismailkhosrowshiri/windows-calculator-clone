# Windows 10 Style Calculator

A browser-based calculator built with HTML and CSS as an early frontend practice project.

## Overview

This project recreates the visual layout of the Windows 10 calculator interface. It is part of my frontend learning portfolio and demonstrates an early step in practicing page structure and styling.

## Tech Stack

- HTML
- CSS

## Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.

No build tools or package installation are required.

## Project Status

This is an early learning project. The repository is preserved as part of my development history.
